Who is allowed to point an AI agent at what?

sprintailab is an open-source MCP proxy that sits between your AI agent and REA (Reverse Engineer Anything). It checks authorization, enforces risk tiers on all 207 tools, and logs every decision in a tamper-evident audit trail.

View on GitHub Architecture and diagrams

The problem

AI agents can now analyze binaries, Android apps, Electron apps, websites and firmware without source code. That helps with legacy modernization, vendor due diligence, interoperability and first-pass security review. It is also easy to misuse. IT services teams need controls they can explain to a client.

What sprintailab enforces

Authorization per target

A person declares ownership or written permission for a folder, origin, device or package. Scoped, expiring, revocable.

Risk tiers

All 207 REA tools classified 0 to 3. Unknown tools are denied. Tools that execute code stay blocked until a sandbox exists.

Audit log

Hash-chained record of who, which tool, which targets, under which authorization. Verifiable from the CLI.

REA stays unmodified

Included as a submodule and run as a normal process, so upstream updates are a version bump.

How a call is decided

StepResult
Tool not on the approved listDenied (R1)
Tool above this deployment's tier limitDenied (R2)
Tier 3: executes or modifiesDenied until sandbox exists (R4)
Target not covered by an active authorizationPerson is asked, or denied (R3, R5)
CoveredForwarded to REA, result and evidence id logged

Try it

The offline demo needs no REA and no real target. It shows a denied call, an authorization, an allowed call, refused tools and a tampered audit log being caught.

git clone --recurse-submodules https://github.com/nezuko-afk/sprintailab.git
cd sprintailab && npm install && npm run build && npm test
node examples/demo.mjs
claude mcp add sprintailab -- node "$PWD/dist/index.js"

Honest status

Open source under the MIT License. Working end to end against REA 6.6.0 with 73 automated tests. Not built yet: sandbox, roles and second approval, central audit store, India-specific legal review. Not legal advice.

FAQ

Is it a fork of REA?

No. REA (MIT, by morluto) runs unmodified behind the proxy.

Which AI agents work with it?

Any client that supports local stdio MCP servers, such as Claude Code, Cursor, Codex and Gemini CLI.

Does it prevent someone running REA directly?

No. It governs use through this product.

Is reverse engineering legal in India?

It depends on the software, licence and purpose. Take it to counsel; the open questions are listed in the repo.
