# Copy for the sprintailab.com page

Suggested page: **Governed AI reverse engineering** (for example sprintailab.com/open-source).

**Headline:** Let AI agents analyze software, only where a person said yes.

**Lead:** REA (Reverse Engineer Anything) gives an AI agent real analysis power over binaries, apps, websites and firmware. sprintailab is our open-source control layer around it. Every target needs a person's authorization, every tool is risk-tiered, and every decision lands in a tamper-evident audit log.

**Three points**
1. **Authorize every target.** A person declares ownership or written permission for a folder, origin, device or package, with an expiry. The agent cannot fill that step.
2. **Tier every tool.** All 207 REA tools are classified. Anything that runs or modifies code stays blocked until a sandbox exists, and unknown tools are denied.
3. **Prove what happened.** A hash-chained log records each decision, and a single command checks it.

**Honest status line:** Early and open source (MIT). Working end to end against REA 6.6.0. Sandbox for code-executing tools, roles and central deployment are still to build.
