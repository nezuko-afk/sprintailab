# Code of conduct

Be respectful and constructive. Harassment, personal attacks and discriminatory
language are not accepted. Disagree with ideas, not people.

This project is about using powerful analysis tools responsibly. Do not use the
issue tracker or discussions to request help analyzing software you do not own or
have permission to analyze.

Report problems to contact@sprintailab.com. Maintainers may remove comments or
block participants who break these rules.
